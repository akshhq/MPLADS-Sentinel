# MASTER FRONTEND IMPLEMENTATION PROMPT — MPLADS SENTINEL

You are the lead frontend architect, UI/UX engineer, and senior frontend developer for this project.

Your task is to take the complete frontend specification in:

MPLADS_Sentinel_Frontend_UI_UX_Specification.md

and build the MPLADS Sentinel frontend in the existing repository.

============================================================
1. READ THE SPECIFICATION FIRST — DO NOT START CODING IMMEDIATELY
============================================================

Before modifying anything:

1. Locate and read the ENTIRE file:
   MPLADS_Sentinel_Frontend_UI_UX_Specification.md

2. Read it completely, not just the first few sections.

3. Extract and understand:
   - product purpose
   - target users
   - information architecture
   - page hierarchy
   - URL structure
   - navigation
   - layouts
   - components
   - design language
   - risk system
   - evidence system
   - investigation workflow
   - AI interfaces
   - API expectations
   - data models
   - responsive requirements
   - accessibility requirements
   - demo requirements
   - MVP priorities
   - definition of done

4. Treat that file as the PRIMARY frontend specification.

5. Do not replace the specification with your own interpretation simply because you prefer another architecture or design.

6. If something is explicitly defined in the specification, follow it.

7. If something is not defined, make the smallest reasonable implementation decision necessary and keep the architecture extensible.

8. Do not invent unsupported product capabilities, government integrations, fraud claims, datasets, AI accuracy numbers, evidence, or statistics.
